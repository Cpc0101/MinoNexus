MINO / 部署与镜像

服务与工作台，各自部署。

Nexus 提供 API 和执行中枢，Workbench 独立构建、独立发布到静态站点或 CDN。

macOS · 本地构建 wheel + launchd

正式发布只产出腾讯云使用的 AMD64 镜像；macOS 如需本地运行，可从源码构建只包含服务端的 wheel。需要 Python 3.12 或以上及 pipx。

python -m build --wheel --outdir dist
pipx install ./dist/mino_nexus-X.Y.Z-py3-none-any.whl
mino-nexus service install
mino-nexus service status

将 X.Y.Z 替换为实际版本。Nexus API 监听 http://127.0.0.1:50104/，Workbench 在独立部署中配置该地址。

查看本地构建与安装说明

腾讯云 · Nexus Docker

只发布腾讯云所需的 Linux AMD64 镜像；镜像只包含 Nexus，使用独立数据卷。

export MINO_NEXUS_VERSION=X.Y.Z
docker compose pull
docker compose up -d

在 Compose 文件所在目录执行并指定具体版本。不再生成 ARM64 镜像或离线镜像包。

获取 Compose · 查看镜像版本

Workbench · 独立静态部署

Workbench 在自己的仓库构建，通过 VITE_NEXUS_URL 指向 Nexus，再发布到静态站点或 CDN。跨域部署时在 Nexus 设置 MINO_WORKBENCH_ORIGINS。

查看 Workbench 仓库

Scout · 设备执行节点

Scout 单独安装在连接设备的机器，不放进 Nexus 容器，连接 ws://服务器:50104/node。Workbench 由浏览器访问，独立部署，不安装到设备节点。

升级与已有安装

腾讯云 Nexus 升级使用新的固定镜像 tag，Workbench 按自己的静态发布版本升级。升级前停写并备份；自动迁移前备份当前暂未实现。旧安装目录保留，迁移需复制到新目录后验收，不能直接覆盖业务库。

完整部署、升级与回滚说明

后续发布不再上传 wheel、sdist 或离线镜像附件；只保留 GHCR 中的固定版本镜像。

开发环境：Nexus 50101 / Workbench 60101。两者独立启动、独立部署。
