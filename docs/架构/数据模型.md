# 数据模型

**Nexus 是业务状态的唯一归属方。** Scout 不访问 Nexus 数据库；渠道消息真源在 Scout 本地。

`mino.db`（SQLite），表定义在 `models/*.py`，一张表一个文件。**改字段必须同步本文**。

## 1. 库文件与路径

| 环境 | 数据根 | 库文件 |
|---|---|---|
| 开发（`--dev`） | `~/.mino-dev/nexus/`（可用 `MINO_NEXUS_DEV_DATA_DIR` 覆盖） | `mino.db` |
| 正式（`--prod` / `service`） | `~/.mino/nexus/`（可用 `MINO_NEXUS_DATA_DIR` 覆盖） | `mino.db` |
| Docker | `/data` | `mino.db` |

开发与正式**禁止共用或互相包含目录**，启动时校验环境标记。旧安装目录不自动迁移。

## 3. 写库纪律

- **禁止在调试时直接对 `mino.db` 增删改。** 用接口或会话写入。
- 迁移前用 SQLite backup API 生成一致备份（0600），不覆盖旧备份。
- 历史无 owner 的节点认领在单个事务内同时更新 `nodes`、未归属 `m_device` 与 `node_credentials`。
- 业务状态进 sqlite。**禁止再给项目 / 应用 / 设备 / 跑批 / 账号 / 设置 / 能力目录加 JSON 真源。**
