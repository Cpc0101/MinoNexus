# 不要恢复的东西

这张表是「已经删了、而且不要加回来」的清单。**历史文档里提到它们的地方，一律以本文为准。**

重新启动任何一项都需要新的明确需求，不能因为某份旧方案里写着就恢复。

## 1. 代码

| 已删除 | 曾经是什么 | 现在该怎么做 |
|---|---|---|
| `loop/agent_loop.py` | 逐步决策循环（observe → decide → dispatch） | 执行在 Scout，脚本自己写顺序。Nexus 只派发 `script.run` |
| `loop/registry.py` | 决策循环的 guard 注册表 | 删掉的守卫不要加回；需要拦就在脚本里 `case.fail` |
| `loop/execution/` | 决策循环的阶段拆分 | — |
| `loop/session_ensure.py` | prep 收工时的会话核对 | 会话事实由 Scout 上报的 `session_events` 表达 |
| `loop/llm_screenshot_gate.py` / `device_display_guard.py` | 决策期截图节制 | 截图由脚本显式 `case.screenshot()` 触发 |
| `services/` 整个包（80 文件） | 上游大平层 | 按层落位：用例进 `casework/`、资源进 `resources/`、身份进 `platform/` |
| `remote` executor / ClawNode 通道 | 无 USB 时的反连执行 | 只有 `adb` / `ios_wda` / `playwright` / `mac` / `win` |
| `collab_*` / `rCollabWorkspace.py` / `rMinoBots.py` | 多 Agent 工作层 | 协作在 IM / 助手对话里做 |
| `engines/` / `EngineFactory` | 上游驱动引擎层 | 从未搬迁；executor + `platform/<os>/` 就够 |
| `probe/` 目录 | 上游设备探测 | 连通性只来自 Scout 的 `REGISTER` / `HEARTBEAT` |

## 2. 前端

| 已取消 | 说明 |
|---|---|
| **MinoWorkbench** | 桌面端前端，已取消，仓库不存在 |
| **MinoWorkbench** | Web 管理后台，已取消，仓库不存在 |

唯一前端是 **MinoWorkbench**，编译成静态文件内置在 Nexus wheel 里，同源 `:50104` 访问。**没有独立的 60104 服务**，没有 Workbench 独立安装包，没有 Electron。

历史文档里出现的 `MinoWorkbench/docs/SCOUT_INSTALL.md`、`Workbench 扩展包页`、`studio_nav`、`/testing/:appId` 等入口，一律以 Workbench 现有页面为准。

## 3. 机制

| 已取消 | 说明 |
|---|---|
| Nexus / Scout / Workbench 在线自更新入口 | 升级用新 wheel 或更新容器 tag；在线自更新 HTTP/MCP 工具已移除。Scout 自己的分层更新仍在 |
| 来源后台周期读取、失败退避、自动解析、每日预算释放 | 只保留手动导入 |
| 历史 SN / 引用全量迁移 | 已取消迁移交付；「以后清空再导入」不是现在删数据的授权 |
| HITL / 人工输入 / persona 迁移与注册 | 不迁移、不注册、不进模型菜单 |
| `executor_order` 多元素列表 / 失败换路 | 单动作必须恰好一个 executor，任何状态都结束本次尝试 |
| `MINO_AI_API_KEY` 等环境变量覆盖 | 模型配置按执行账号持久化，不回退环境变量或共享 Key |
| `case.event` | 脚本自定义事件，已删除。业务差异写成 `scripts/` 函数 |
| 把场景步骤登记成新的 `catalog_entries` | 业务编排属于脚本，不属于能力目录 |
| 用 `note` 充当执行步骤 | `note` 只记证据 |
| 把 `pages/` 写回 `nav_fsm*` / 控件表 | 应用逻辑真源是仓库里的 `pages/` |

## 4. 文档

历史架构演进方案、事故复盘、上游搬迁账、批跑流水账**已全部删除**，不再保留归档目录。

要了解过去做过什么，查 git 历史（`git log --all -- docs/`）。**不要按旧文档设计新功能。**
